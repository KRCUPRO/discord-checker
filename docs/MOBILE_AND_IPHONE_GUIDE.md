# 📱 Mobile, iPhone, iPad & Tablet Cloud Execution Guide
# (모바일/아이폰/아이패드/태블릿 기종 무관 100% 브라우저 기반 구동 가이드)

> **"PC가 없어도, 앱을 설치하지 않아도, 아이폰·아이패드·갤럭시·태블릿의 모바일 웹 브라우저(Safari/Chrome)만 열면 1분 만에 24시간 클라우드 체커가 가동됩니다."**

---

## 🌟 핵심 장점 (Why Mobile Cloud?)

1. **기종 및 OS 100% 무관 (Device-Agnostic)**:
   - 🍏 **Apple iOS**: iPhone 11~16 Pro Max, iPad, iPad Air, iPad Pro (Safari 브라우저)
   - 🤖 **Android**: 갤럭시 S/Z/A 시리즈, 갤럭시 탭, 샤오미, 픽셀 등 (Chrome/삼성 브라우저)
   - 💻 **PC/Mac/Chromebook**: 브라우저가 실행되는 모든 장치
2. **설치 0개 (Zero Installation & Zero Rooting)**:
   - 탈옥(Jailbreak), 루팅(Rooting), 별도 리눅스 환경(Termux) 설치 불필요.
3. **배터리 소모 0% & 기기 꺼짐 무관 (24/7 Cloud Background)**:
   - Google Apps Script를 가동하면 스마트폰 전원을 끄거나 비행기 모드로 전환해도 구글 클라우드에서 24시간 365일 닉네임 점검 지속.
4. **모바일 실시간 알림**:
   - 가용 닉네임 발견 시 스마트폰 **Discord 앱 알림** 및 **Google Sheets 앱**으로 실시간 푸시.

## 📱 방법 1: Google Apps Script 24/7 무인 체커 (기기 꺼짐 무관)

스마트폰 하나만으로 컴퓨터 없이 24시간 365일 닉네임을 수집하는 가장 강력한 방법입니다.

### [3단계 모바일 설정 순서]
1. **스마트폰 브라우저(Safari/Chrome)에서 접속**:
   - [script.google.com](https://script.google.com/)으로 이동하여 Google 계정으로 로그인합니다.
2. **새 프로젝트 생성 및 코드 붙여넣기**:
   - 좌측 상단 **[+ 새 프로젝트]** 클릭.
   - 프로젝트 내 기본 코드를 지우고, [`gas/D4UC_Checker.js`](../gas/D4UC_Checker.js) 전체 코드를 복사하여 붙여넣습니다.
   - 상단 `CONFIG`에서 `DISCORD_WEBHOOK_URL`에 본인의 디스코드 웹훅 주소를 입력합니다 (선택 사항).
   - 저장 아이콘(💾)을 누릅니다.
3. **가동 시작**:
   - 상단 실행 함수 드롭다운에서 **`initD4UCChecker`**를 선택하고 **[실행]**을 누릅니다.
   - 최초 권한 승인 창(고급 ➔ 이동 ➔ 허용)을 승인하면 즉시 예약 트리거가 걸리며, **이제 스마트폰 화면을 끄셔도 24시간 자동으로 계속 돌아갑니다!**

### [모바일 확인]
- 스마트폰에 **Google Sheets 앱**을 설치해두면 `D4UC_Tracker` 시트에 새 닉네임이 뜰 때마다 실시간으로 확인할 수 있습니다.
- Discord 앱으로 초록색 알림이 날아오면 링크를 눌러 1초 만에 선점하세요!

## ⚡ 방법 2: Google Colab 대화형 Web GUI (아이폰/태블릿 브라우저)

아이폰 Safari나 아이패드 화면에서 멋진 Cyberpunk 다크 대시보드를 보면서 조작하고 싶을 때 사용합니다.

### [3단계 모바일 실행 순서]
1. **모바일 브라우저로 Colab 노트북 열기**:
   - 아이폰/안드로이드 브라우저에서 `D4UC_Google_Colab.ipynb`를 엽니다.
2. **구글 드라이브 마운트 및 원클릭 환경 준비**:
   - **1단계 셀 [▶]**을 눌러 고속 의존성을 30초 만에 설치합니다.
   - **2단계 셀 [▶]**에서 탐색 모드(Permutation, Hybrid 등)와 글자수(4자)를 선택합니다.
3. **대화형 Web GUI 가동**:
   - **3단계 셀 [▶]**을 누르면 브라우저 셀 출력창 안에 **모던 반응형 다크 대시보드**가 직접 렌더링됩니다!
   - 6대 KPI(초당 속도, 총 검사, 가용 닉네임 등)와 실시간 발견 닉네임 표가 모바일 화면에 맞춰 자동으로 리사이징됩니다.
   - 발견된 닉네임 옆의 **[복사 📋]** 또는 **[등록 🚀]** 버튼을 모바일 터치 한 번으로 즉시 실행할 수 있습니다.

## 💡 자주 묻는 질문 (FAQ)

### Q1. 아이폰(iOS)에서 별도 앱이나 탈옥이 필요한가요?
> **전혀 필요 없습니다.** iOS 순정 Safari 브라우저만 있으면 Google Colab과 Google Apps Script 모두 100% 정상 작동합니다.

### Q2. 스마트폰 배터리가 닳거나 Wi-Fi가 끊기면 어떻게 되나요?
> **Google Apps Script** 방식은 구글 클라우드 서버에서 독자적으로 돌아가므로 스마트폰 전원이 꺼지든, 데이터가 끊기든 24시간 365일 1초도 멈추지 않고 계속 검사합니다.

### Q3. 여러 대의 기기(아이폰 + 갤럭시 + PC)에서 동시에 확인할 수 있나요?
> 네, 결과는 사용자의 Google Drive(`available_usernames.txt`) 및 Google Sheets(`D4UC_Tracker`)에 실시간 동기화되므로, 어떤 기기에서든 동일한 결과를 실시간으로 열람하실 수 있습니다.
