## 🚀 1-Minute Schnellstartanleitung

### Schritt 1: Google Apps Script Projekt erstellen
1. Öffnen Sie [Google Apps Script](https://script.google.com/) und erstellen Sie `D4UC 24/7 Checker`.

---

### Schritt 2: Code einfügen & konfigurieren
1. Fügen Sie [`gas/D4UC_Checker.js`](https://github.com/KRCUPRO/discord-checker/blob/main/gas/D4UC_Checker.js) ein.
2. Konfigurieren Sie `CONFIG` und speichern Sie.

---

### Schritt 3: Initialisierung starten
1. Wählen Sie **`initD4UCChecker`** und führen Sie es aus.
2. Berechtigungen erteilen.

---

## 📊 Ergebnisse
Speicherung auf Google Drive, Google Sheets und Discord-Webhooks.

---

## 🌐 Multi-Account Sharding (100k~240k Checks/Tag)
Verwenden Sie [`gas/D4UC_MultiAccount_Worker.js`](https://github.com/KRCUPRO/discord-checker/blob/main/gas/D4UC_MultiAccount_Worker.js) auf zusätzlichen Konten.

---

## 🛑 Beenden
Führen Sie **`stopD4UCChecker`** aus.
