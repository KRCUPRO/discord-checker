## 1. 실물 스마트폰 "서버 미연결" 문제의 근본 원인 분석

### 🔍 현상 재현
사용자가 실물 삼성 갤럭시 스마트폰(SKT 통신사)에 D4UC 안드로이드 APK를 설치하고 앱을 실행했을 때, 상단에 `⚠️ 서버 미연결 (D4UC 서버 URL 확인)` 경고 배지가 출력되며 하단의 `▶️ 탐색 시작` 버튼을 눌러도 탐색이 시작되지 않는 문제 발생.

### ⚙️ 기저 메커니즘 분석
1. **에뮬레이터 전용 루프백 IP(`10.0.2.2`) 하드코딩의 한계**:
   - 기존 APK의 기본 서버 URL은 `http://10.0.2.2:5000`으로 지정되어 있었습니다.
   - `10.0.2.2`는 안드로이드 스튜디오 에뮬레이터(AVD)에서 호스트 PC의 `127.0.0.1`로 접근하기 위해 제공되는 가상 라우팅 IP입니다.
   - 실물 스마트폰(Physical Hardware)은 독립된 네트워크 인터페이스(Wi-Fi 또는 LTE/5G)를 사용하므로, `10.0.2.2`로 패킷을 전송하면 무조건 `Connection Refused` 또는 타임아웃이 발생합니다.
2. **이동통신사(LTE/5G) 어댑터 우선 열거로 인한 Wi-Fi IP 미감지 결함**:
   - 퀄컴/엑시노스 기반 스마트폰(삼성 갤럭시 등)은 네트워크 어댑터 열거 시 모바일 데이터 인터페이스(`rmnet_data0`)가 Wi-Fi 인터페이스(`wlan0`)보다 먼저 반환됩니다.
   - 기존 로컬 IP 감지 로직은 단순 첫 번째 어댑터를 채택하여 이동통신사 셀룰러 사설 IP를 Wi-Fi 서브넷으로 오판하는 결함이 있었습니다.
   - 본 버전에서는 `wlan` 및 `eth` 인터페이스를 최우선으로 선별하도록 보정하여 홈 Wi-Fi 서브넷이 100% 정확하게 감지됩니다.
3. **미연결 시 UI 레이아웃 붕괴 (Header Cramping)**:
   - `⚠️ 서버 미연결 (D4UC 서버 URL 확인)`이라는 26자의 긴 문자열이 모바일 헤더의 작은 배지 안에 억지로 들어가면서, 헤더의 브랜드명, 언어 선택 셀렉트박스와 충돌하여 줄바꿈 및 화면 상단 카메라 펀치홀/노치 영역과 겹쳐서 표시되는 시각적 결함이 발생했습니다.
4. **무응답 실패(Hard Failure) 및 미연결 액션 시트 미비**:
   - PC 서버가 켜져 있지 않거나 Wi-Fi IP가 입력되지 않은 상태에서 `▶️ 탐색 시작`을 누르면 비동기 `fetch()`가 조용히 거부(Reject)되어 사용자가 원인을 파악하기 어려웠습니다.
   - 개편 후에는 미연결 시 `⚠️ 서버 미연결 안내` 액션 시트가 즉시 팝업되어, 1-Tap으로 `[🟣 독립 시연 모드로 바로 시작 (권장)]`, `[🌐 PC 서버 연결 설정 마법사]`, `[🔍 같은 Wi-Fi PC 자동 탐색]` 중 하나를 직관적으로 선택할 수 있습니다.

## 2. 스마트 네트워크 감지 및 멀티 프로브(Multi-Probe) 아키텍처

D4UC v12.3.1은 실물 스마트폰과 원격 브라우저 접속을 위해 다계층 자동 탐색 엔진을 도입했습니다.

```
[Android APK / Mobile Web]
        │
        ├── 1. 저장된 사용자 지정 URL (localStorage / SharedPreferences)
        ├── 2. 스마트폰 Wi-Fi 서브넷 감지 (AndroidBridge.getDeviceLocalIp -> 192.168.219.*)
        ├── 3. 백엔드 네트워크 정보 엔드포인트 (/api/network_info -> primary_ip, recommended_urls)
        ├── 4. 에뮬레이터 환경 감지 (AndroidBridge.isEmulator -> 10.0.2.2:5000)
        └── 5. 로컬 루프백 (localhost:5000 / 127.0.0.1:5000)
        │
        ▼ (병렬 프로브: AbortSignal 700ms)
[가장 빠른 응답 서버 자동 연결 ➔ 레이턴시 측정 ➔ 상태 배지 🟢 전환]
```

### 📡 백엔드 `/api/network_info` 엔드포인트
- 서버가 실행 중인 PC의 모든 활성 IPv4 어댑터를 스캔하여 가상 IP(APIPA 169.254.x.x)와 루프백을 제외한 사설 LAN IP(192.168.x.x, 10.x.x.x)를 우선순위화하여 클라이언트에 제공합니다.
```json
{
  "status": "ok",
  "hostname": "DESKTOP-PC",
  "port": 5000,
  "primary_ip": "192.168.219.110",
  "lan_ips": ["192.168.219.110", "10.0.0.100"],
  "recommended_urls": [
    "http://192.168.219.110:5000",
    "http://10.0.0.100:5000"
  ]
}
```

## 3. 서버 연결 마법사 (Server Connection Assistant Modal) UX 설계

사용자가 네트워크 지식이 없어도 원터치로 연결할 수 있도록 직관적인 다이얼로그 마법사를 신설했습니다.

1. **상태 배지 원터치 인터랙션**:
   - 상단 우측의 상태 배지(`🔴 미연결`, `🟢 32ms`, `🟡 확인 중`) 또는 상단 알림 배너를 터치하면 언제든지 연결 마법사가 즉시 팝업됩니다.
2. **실시간 핑(Ping) 테스트 게이지**:
   - 서버 주소 입력창 우측의 `[⚡ 핑 테스트]` 버튼을 누르면 즉시 1,500ms 타임아웃의 통신 테스트를 수행하고, 실시간 왕복 지연시간(RTT)을 `🟢 32ms — 정상 연결됨` 또는 명확한 조치 가이드(`🔴 연결 실패 — 동일 Wi-Fi 여부 및 PC 방화벽 5000번 포트 확인`)로 표시합니다.
3. **스마트 서브넷 프리셋 원터치 버튼**:
   - 스마트폰이 Wi-Fi에 연결되어 있으면 단말기의 로컬 IP(예: `192.168.219.45`)로부터 서브넷 접두사(`192.168.219.`)를 자동 추출하여 프리셋 버튼을 생성합니다. 사용자는 PC의 마지막 번호만 입력하면 즉시 연결됩니다.
4. **로컬 네트워크 자동 탐색 (Auto Scan)**:
   - `[🔍 로컬 네트워크 자동 탐색]` 버튼을 누르면 현재 서브넷의 주요 호스트 번호(`.1`, `.100`, `.110`, `.120` 등)를 순차 스캔하여 D4UC 서버가 응답하는 IP를 자동으로 찾아내어 즉시 바인딩합니다.

## 4. 독립 시연 및 오프라인 자가 진단 모드 (Standalone Mock Mode)

PC가 꺼져 있거나, 카페/외부에서 이동 통신망(LTE/5G)으로 스마트폰 단독으로 앱을 시연할 수 있도록 **클라이언트 사이드 독립 시연 엔진(`MockEngine`)**을 내장했습니다.

### 🎮 독립 시연 모드의 핵심 특징
- **PC 백엔드 0% 의존성**: 서버 연결이 없어도 앱 단독으로 전체 라이프사이클 구동 가능.
- **고정밀 텔레메트리 시뮬레이션**:
  - 실시간 RPS(초당 검사 속도: 10.0 ~ 25.0 req/s 플럭투에이션)
  - 검사 총계, 가용 발견 수, 선점 닉네임, 429 레이트 리미트 회피 노드 교체 카운터 실시간 증가
  - 40ms ~ 85ms 지연시간(Latency) 게이지 연동
- **희귀 닉네임 가용 발견 시뮬레이션**:
  - 현실적인 닉네임(`krcu`, `vibe_99`, `zeus_7`, `nova_x`, `sol_88` 등)이 가용 목록에 실시간 추가되며, 진동 햅틱 피드백 및 원터치 클립보드 복사 토스트가 완벽하게 작동합니다.
- **실시간 캔버스 속도 파형 렌더링**:
  - 실제 엔진 가동 시와 동일하게 네온 블루/시안 그라데이션 베지어 곡선 파형이 살아 움직이며 렌더링됩니다.
- **안전한 모드 전환**:
  - 언제든지 상단 배지(`🟣 시연 모드`)를 눌러 실 서버 모드로 즉시 복귀할 수 있습니다.

## 5. 모바일 UI/UX 개편 및 노치/상태바 세이프에어리어(Safe Area) 최적화

### 📱 1. 삼성 갤럭시 상태바 및 카메라 홀 겹침 원천 차단
- **CSS 환경 변수 고도화**:
  ```css
  :root {
    --safe-top: max(env(safe-area-inset-top, 0px), 20px);
    --safe-bottom: max(env(safe-area-inset-bottom, 0px), 16px);
    --safe-left: max(env(safe-area-inset-left, 0px), 12px);
    --safe-right: max(env(safe-area-inset-right, 0px), 12px);
  }
  ```
- **스티키 헤더 스크롤 버그 수정**:
  - 기존에는 `body`에만 상단 패딩이 적용되어 있어 스크롤 시 `header`가 뷰포트 맨 위(`top: 0`)로 붙으면서 카메라 펀치홀 및 통신사 상태바(`SKT 6:24`) 뒤로 파고드는 문제가 있었습니다.
  - `header` 자체에 `padding-top: max(var(--safe-top), 16px);`를 적용하고 `backdrop-filter: blur(12px)` 글래스모피즘을 입혀, 스크롤을 내리더라도 상태바 영역과 명확히 분리되도록 수정했습니다.

### 🏷️ 2. 헤더 브랜드 및 상태 배지 반응형 리디자인
- **간결한 브랜드 마크**:
  - 기존의 장황한 `D4UC Mobile Web - Discord Username Checker v12.3.0` 텍스트를 컴팩트한 로고 심볼 `⚡`, 브랜드 타이틀 `D4UC`, 그리고 릴리즈 뱃지 `v12.3.0 / APK`의 2열 구조로 압축하여 360px 폭의 좁은 화면에서도 가로 공간을 과도하게 차지하지 않도록 개선했습니다.
- **4단계 직관적 상태 알약 배지**:
  - `🟢 32ms` (연결 정상 - 핑 지연시간 표기)
  - `🟡 확인 중...` (서버 탐색 및 검증 진행)
  - `🔴 미연결` (미연결 - 탭하여 마법사 열기)
  - `🟣 시연 모드` (독립 시연 모드 가동 중)

### 🔘 3. 하단 플로팅 액션 바 (Floating Bottom Action Bar)
- 갤럭시 네비게이션 제스처 바(`|||` 또는 홈 인디케이터 바)와 겹치지 않도록 `calc(var(--safe-bottom) + 8px)` 하단 패딩 적용.
- 모바일 엄지 영역(Thumb Zone)을 고려한 48px 이상의 대형 터치 타깃 및 `active: transform: scale(0.97)` 촉각적 피드백 제공.

## 6. 실시간 텔레메트리 캔버스 차트(Speed Canvas) 빈 화면 UX 개선

### 🚫 기존 문제점
- 대기 상태이거나 검사 데이터 포인트가 2개 미만일 때, 캔버스를 단순히 `clearRect()`한 채 방치하여 UI 중앙에 휑한 '검은색 빈 상자(Black Void)'가 남아있어 앱이 멈춘 것처럼 보였습니다.

### ✨ 개선된 캔버스 UX
1. **사이버펑크 그리드 및 가이드라인**:
   - 캔버스 배경에 은은한 톤과 25%, 50%, 75% 높이의 대시(`[4, 4]`) 가이드라인을 렌더링.
2. **대기 상태(Idle Skeleton) 인포메이션**:
   - 대기 상태일 때는 차분한 베이스라인과 함께 정돈된 상태 안내 메시지를 중앙에 렌더링:
     `⚡ 엔진 대기 중 — [탐색 시작]을 누르면 실시간 속도 그래프가 활성화됩니다`
     (독립 시연 모드일 때는 `🟣 시연 모드 대기 중 — [탐색 시작]을 누르면 시뮬레이션 파형이 시작됩니다`)
3. **가동 상태(Active Neon Spline Wave)**:
   - 데이터가 들어오면 블루/시안 네온 그라데이션 베지어 곡선 및 면적 채우기, 현재 측정 지점의 발광 인디케이터 서클이 유려하게 렌더링되며, 헤더 우측의 피크(`최고: 18.5 req/s`)가 실시간 갱신됩니다.

## 7. 실물 스마트폰 ➔ PC Wi-Fi 연동 단계별 가이드

### 1단계: PC에서 D4UC Web 서버 실행
PC에서 콘솔 또는 실행 파일로 D4UC를 가동합니다:
```bash
python src/web_gui.py
```
콘솔에 아래와 같이 스마트폰 접속용 LAN 주소가 출력됩니다:
```
=====================================================================
🚀 [D4UC Mobile Web GUI] Server running at http://localhost:5000
📱 Mobile Device URL (same Wi-Fi): http://192.168.219.110:5000
✨ PWA & Android APK Remote Control: Active
=====================================================================
```

### 2단계: 스마트폰에서 Wi-Fi 연결 확인
- 스마트폰(Galaxy)의 Wi-Fi가 PC와 동일한 공유기(예: 같은 가정용 Wi-Fi)에 연결되어 있는지 확인합니다.

### 3단계: APK 앱에서 연결
1. 스마트폰에서 **`D4UC Discord Checker`** 앱을 엽니다.
2. 상단의 `🔴 미연결` 알약 배지나 노티스 배너를 터치합니다.
3. 프리셋 목록에서 PC 주소(예: `192.168.219.110:5000`)를 선택하거나 직접 입력합니다.
4. `[⚡ 핑 테스트]`를 눌러 `🟢 응답 성공`을 확인합니다.
5. `[💾 설정 저장 및 닫기]`를 누르면 상단 배지가 `🟢 34ms`로 바뀌며 연동이 완료됩니다!
6. 하단의 `[▶️ 탐색 시작]`을 터치하여 실시간 고속 검사를 제어합니다.

> **방화벽 팁**: 만약 핑 테스트가 실패한다면 Windows Defender 방화벽에서 포트 `5000` (TCP 인바운드)이 허용되어 있는지 확인하세요.
