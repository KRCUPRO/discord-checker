## 📱 iOS / iPadOS 환경 특징 및 아키텍처

Apple iOS 환경의 샌드박스 보안 정책상 스마트폰 자체에서 직접 파이썬 데몬과 와이어가드 유저스페이스 바이너리를 직접 컴파일 실행하는 것은 제한됩니다. 대신 D4UC는 **모바일 터치 최적화 PWA(Progressive Web App) 기술**을 채택하여 다음 아키텍처를 제공합니다:

```text
+------------------------------------+          +--------------------------------------+
|  Apple iPhone / iPad (iOS Safari)  |          |   D4UC Host Engine (PC / VPS / Docker)|
|                                    |          |                                      |
|  • 주소창 없는 전체화면 PWA 앱     |  HTTP/WS |  • Python 3.12 Core (port 5000)      |
|  • 30ms 실시간 캔버스 그래프       |<========>|  • Chrome 131 BoringSSL TLS Engine   |
|  • 1-Tap 닉네임 클립보드 복사      | (LAN/VPN)|  • 1:1 WireGuard User-space Tunnels  |
|  • 원격 핫스왑 (모드/워커/프록시)   |          |  • SQLite WAL Transaction DB         |
+------------------------------------+          +--------------------------------------+
                  |                                                |
                  | (0.1초 즉시 푸시 알림)                           |
                  v                                                v
    [Discord iOS App 모바일 알림] <----------------------- [Discord Webhook Push]
```

## 📲 Safari PWA 홈 화면 추가 (주소창 없는 네이티브 앱)

App Store 심사나 복잡한 프로비저닝 없이 Safari의 내장 PWA 엔진을 통해 10초 만에 홈 화면 네이티브 앱을 생성합니다.

[![D4UC Mobile Web GUI](../assets/mobile_web_main.png)](IOS_GUIDE.md)

### 단계별 설치 절차:
1. PC, 리눅스 VPS, 또는 맥에서 D4UC 웹 서버를 구동합니다:
   ```bash
   python src/web_gui.py --port 5000
   ```
2. iPhone 또는 iPad에서 **Safari 브라우저**를 실행합니다.
3. 동일 Wi-Fi 망에 연결된 호스트의 로컬 IP로 접속합니다:
   ```text
   http://192.168.0.x:5000
   ```
4. Safari 하단 툴바 중앙의 **[공유 버튼 (네모+위쪽 화살표 ⬆️)]**을 탭합니다.
5. 메뉴를 아래로 스크롤하여 **`[홈 화면에 추가]`**를 탭합니다.
6. 우측 상단의 **[추가]**를 누르면 홈 화면에 보라색 **D4UC Web** 아이콘이 설치됩니다.
7. 홈 화면 아이콘을 탭하면 브라우저 주소창과 툴바가 사라진 **전체화면 네이티브 모바일 앱**으로 작동합니다.

## 🎮 모바일 터치 인터페이스 및 원격 제어 기능

- **실시간 대형 텔레메트리 카드**:
  - RPS (초당 탐색 속도), 가용 닉네임, 총 검사수, 선점수, 429 핫스왑 횟수, 평균 응답 시간(ms)을 30ms 단위로 실시간 표시합니다.
- **HTML5 속도 캔버스 그래프**:
  - 외부 무거운 프레임워크 없이 바닐라 자바스크립트로 60fps 부드러운 속도 곡선을 렌더링합니다.
- **원격 파라미터 핫스왑**:
  - 침대에 누워서도 스마트폰 터치만으로 8대 생성 모드(하이브리드, 순열, 사전, 대칭, 숫자, 마스크, 조합, 재점검)를 실시간 변경할 수 있습니다.
  - 슬라이더 터치로 동시성 워커 수(1~50개)를 무중단 확장/축소할 수 있습니다.

## 🔔 Discord Webhook 모바일 실시간 푸시 알림 (0.1초 전송)

희귀 닉네임이 발견되었을 때 PC 앞을 지키지 않아도 iPhone 잠금 화면에 즉각적인 푸시 알림과 진동이 울립니다:

1. 디스코드 서버 설정 ➔ **[연동]** ➔ **[웹후크 만들기]** ➔ 웹후크 URL 복사.
2. D4UC 호스트의 `.env` 파일에 웹후크 등록:
   ```ini
   D4UC_WEBHOOK=https://discord.com/api/webhooks/1234567890/abcdefg...
   ```
3. 가용 닉네임 발견 시 Discord 공식 모바일 앱으로 0.1초 만에 알림이 전송됩니다.

## 📡 iOS SSH 터미널 클라이언트 연동 (Termius, Blink)

파워유저라면 iPhone / iPad의 유명 터미널 앱을 통해 서버의 CLI 대시보드를 직접 감시할 수 있습니다:

1. App Store에서 **`Termius`** 또는 **`Blink Shell`** 다운로드.
2. D4UC 호스트 서버로 SSH 접속.
3. 백그라운드 `tmux` 세션에 연결하여 실시간 Rich 대시보드 확인:
   ```bash
   tmux attach -t d4uc
   ```

## 📥 1-Tap 닉네임 클립보드 복사 및 TXT/CSV/JSON 모바일 저장

- **1-Tap 클립보드 복사**: 발견된 닉네임 목록에서 `[복사]` 버튼을 탭하면 iOS 클립보드로 즉시 복사되며 햅틱 피드백 토스트가 뜹니다.
- **모바일 다운로드**: 대시보드 상단의 `[TXT]`, `[CSV]`, `[JSON]` 버튼을 탭하면 iOS '파일' 앱으로 결과 파일이 즉시 다운로드됩니다.

## 🔧 iOS 전용 문제 해결 및 네트워크 팁

| 현상 | 원인 | 해결 방법 |
| :--- | :--- | :--- |
| **`Safari에서 서버를 찾을 수 없음`** | 아이폰과 호스트가 다른 서브넷이거나 사설 IP 미일치 | 아이폰 설정 ➔ Wi-Fi ➔ 호스트 PC와 동일한 공유기 망에 연결되었는지 확인하고, 호스트의 IPv4 주소를 재확인합니다. |
| **외부 LTE 망에서 접속하려는 경우** | 포트포워딩 미설정 | 공유기 관리자 페이지에서 포트 5000 포트포워딩을 설정하거나, **Tailscale** 무료 사설망 앱을 iPhone과 호스트에 함께 설치하여 1-클릭 암호화 터널로 접속합니다. |
| **PWA 화면이 자동으로 리프레시됨** | iOS 저전력 메모리 정리 | 백그라운드 앱 새로고침 설정을 확인하고 장시간 방치 후 복귀 시 자동 재연결 소켓이 상태를 복원합니다. |
